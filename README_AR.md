# Minecraft Panel — مشروع تطبيق Android

هذا مشروع تطبيق Android مستقل باسم **Minecraft Panel**. يحتوي على شاشة إعداد عنوان لوحة التحكم، ويحفظ العنوان، ثم يفتح اللوحة داخل التطبيق بدلًا من الانتقال إلى متصفح خارجي.

## بناء APK دون Android Studio

أضف المشروع إلى مستودع GitHub ثم استخدم GitHub Actions لبناء APK تلقائيًا:

1. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا باسم `MinecraftPanel`.
2. ارفع **محتويات** هذا المجلد إلى المستودع (بما فيها مجلد `.github/workflows`). اجعل الفرع الرئيسي اسمه `main`.
3. افتح تبويب **Actions** في المستودع. وافق على تفعيل Actions إن طُلب منك.
4. اختر سير العمل **Build Minecraft Panel APK** ثم اضغط **Run workflow** إن لم يبدأ البناء تلقائيًا بعد الرفع.
5. افتح آخر عملية بناء وانتظر أن تصبح خضراء وناجحة.
6. من قسم **Artifacts** في أسفل صفحة العملية، نزّل `MinecraftPanel-debug-apk.zip`.
7. فك ضغط الملف على الهاتف وثبّت `app-debug.apk`. إذا طلب Android الإذن، اسمح بالتثبيت من المصدر الذي نزّلت منه الملف.

لا تحتاج إلى تثبيت Android Studio على الكمبيوتر. يتطلب هذا المسار حساب GitHub واتصالًا بالإنترنت أثناء البناء.

## عنوان لوحة التحكم

العنوان الافتراضي `http://192.168.100.92:8766` يعمل فقط عندما يستطيع الهاتف الوصول إلى سيرفر Ubuntu على هذه الشبكة. خارج المنزل استخدم عنوان Tailscale المناسب مع تشغيل Tailscale على الهاتف والسيرفر. يجب أن تكون لوحة الويب نفسها مشغّلة على السيرفر.

لا تضع رمز دخول اللوحة داخل التطبيق أو في الكود؛ أدخله في صفحة اللوحة عند طلبه. لا تعرض لوحة الإدارة على الإنترنت العام دون HTTPS وحماية مناسبة.
